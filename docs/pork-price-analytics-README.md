# ฟีเจอร์วิเคราะห์ราคาหมูเป็น

## ภาพรวม
ระบบวิเคราะห์และคาดการณ์ราคาหมูเป็นในประเทศไทย พร้อมกราฟแสดงแนวโน้มและการคาดการณ์ราคาในอนาคต

## คุณสมบัติ

### 1. แดชบอร์ดวิเคราะห์
- **สถิติราคา**: แสดงราคาเฉลี่ย, สูงสุด, ต่ำสุด
- **แนวโน้ม**: คำนวณแนวโน้มราคา (เพิ่มขึ้น/ลดลง/คงที่)
- **กราฟ**: แสดงกราฟราคาย้อนหลังและคาดการณ์
- **การคาดการณ์**: ทำนายราคา 7 วันข้างหน้าโดยใช้ Linear Regression

### 2. จัดการข้อมูล
- เพิ่มข้อมูลราคารายวัน
- บันทึกจำนวนหมูเป็นในวันนั้น
- ระบุแหล่งที่มาของข้อมูล (สมาคมผู้เลี้ยงสุกร, กรมปศุสัตว์, ฯลฯ)
- ดูและลบประวัติข้อมูล

### 3. อัลกอริทึมที่ใช้
- **Linear Regression**: คำนวณแนวโน้มเชิงเส้นจากข้อมูลในอดีต
- **Simple Moving Average**: คำนวณค่าเฉลี่ยเคลื่อนที่ 7 วัน
- **Trend Analysis**: วิเคราะห์ทิศทางการเปลี่ยนแปลงของราคา

## การใช้งาน

### สำหรับ Admin:
1. เข้าสู่ระบบด้วยบัญชี Admin
2. เปิดเมนูด้านซ้าย (☰)
3. เลือก **"📊 วิเคราะห์ราคาหมูเป็น"**
4. คลิก **"➕ เพิ่มข้อมูล"** เพื่อบันทึกราคาแต่ละวัน
5. ระบบจะแสดงกราฟและคาดการณ์ราคาโดยอัตโนมัติ

### การเพิ่มข้อมูล:
- **วันที่**: เลือกวันที่ต้องการบันทึก
- **ราคา (บาท/กก.)**: ระบุราคาหมูเป็น เช่น 85.50
- **จำนวนหมู (ตัว)**: จำนวนหมูทั้งหมดในวันนั้น (ไม่บังคับ)
- **แหล่งที่มา**: เลือกแหล่งข้อมูล

### ดูประวัติข้อมูล:
- คลิก **"📋 ดูประวัติ"**
- แสดงรายการข้อมูลทั้งหมดเรียงตามวันที่
- สามารถลบข้อมูลที่ผิดพลาดได้

## การคาดการณ์ราคา

ระบบใช้ **Linear Regression** เพื่อคาดการณ์ราคาในอนาคต:

### สูตร:
```
y = mx + b
โดยที่:
  y = ราคาที่คาดการณ์
  m = slope (ความชัน)
  x = จำนวนวัน
  b = intercept (จุดตัด)
```

### ข้อจำกัด:
- ต้องมีข้อมูลอย่างน้อย 2 วัน
- การคาดการณ์เป็นเพียงแนวโน้มทางสถิติ ไม่ได้รับประกันความแม่นยำ 100%
- เหมาะสำหรับการวางแผนเท่านั้น
