# Pork Price Auto-Scraper

## ภาพรวม

ระบบดึงข้อมูลราคาหมูอัตโนมัติจากเว็บไซต์สมาคมผู้เลี้ยงสุกรแห่งชาติ (swinethailand.com)

## วิธีการทำงาน

### 1. การดึงข้อมูล (Scraping Process)

ระบบจะ:
1. เข้าถึงหน้า index (https://www.swinethailand.com/16866405/ราคาสุกรขุน-ปี-2561-2569)
2. ค้นหาลิงก์ทั้งหมดที่มี URL pattern: `/live-pig-price-DD-MM-YYYY`
3. เรียงลิงก์ตามวันที่ (ใหม่ -> เก่า)
4. ดึงข้อมูลจากแต่ละหน้าโดยมีการหน่วงเวลา 2 วินาที/หน้า
5. แปลงข้อมูลเป็น CSV format

### 2. การแยกข้อมูลราคา

จากหน้าแต่ละวันพระ ระบบจะแยกข้อมูล:

```
ภาคตะวันตก 74-76      → ราคาเฉลี่ย 75.0
ภาคตะวันออก 74-77     → ราคาเฉลี่ย 75.5
ภาคอีสาน 74           → ราคา 74.0
ภาคเหนือ 76-78        → ราคาเฉลี่ย 77.0
ภาคใต้ 76             → ราคา 76.0
ลูกสุกรขุนเล็ก 2,000  → (เก็บไว้แต่ไม่นำเข้า)
```

**ราคาเฉลี่ยทั้งประเทศ**: (75.0 + 75.5 + 74.0 + 77.0 + 76.0) / 5 = **75.5 บาท/กก.**

### 3. การใช้งาน

1. เข้าหน้า **📊 วิเคราะห์ราคาหมูเป็น**
2. คลิก **📦 นำเข้าจำนวนมาก**
3. เลือกจำนวนสัปดาห์ที่ต้องการ (4, 8, หรือ 12 สัปดาห์)
4. คลิก **🔄 เริ่มดึงข้อมูล**
5. รอให้ระบบดึงข้อมูล (ประมาณ 2 วินาที/สัปดาห์)
6. ตรวจสอบข้อมูลโดยคลิก **👁️ ตัวอย่าง**
7. คลิก **✅ นำเข้า** เพื่อบันทึกลงฐานข้อมูล

## ข้อควรระวัง

### การใช้งานอย่างรับผิดชอบ

1. **อย่า scrape บ่อยเกินไป** - ระบบมี delay 2 วินาทีระหว่างแต่ละ request
2. **ดึงเฉพาะข้อมูลที่จำเป็น** - แนะนำไม่เกิน 12 สัปดาห์ต่อครั้ง
3. **ตรวจสอบข้อมูลก่อนนำเข้า** - ใช้ปุ่ม "ตัวอย่าง" เสมอ

### เหตุผลทางกฎหมาย

- ข้อมูลราคาที่ดึงมาเป็น **ข้อมูลสาธารณะ** ที่สมาคมฯ เผยแพร่เพื่อให้ประชาชนเข้าถึงได้
- ระบบดึงข้อมูลอย่าง **ระมัดระวัง** ไม่กระทบต่อเซิร์ฟเวอร์ต้นทาง
- **ไม่มีการคัดลอกเนื้อหาบทความ** หรือสิ่งที่มีลิขสิทธิ์ - ดึงเฉพาะตัวเลขราคา

## การแก้ปัญหา

### ไม่พบลิงก์ข้อมูลราคา

- ตรวจสอบว่า URL pattern เปลี่ยนหรือไม่
- ตรวจสอบ regex pattern ใน `scrapeLatestFromWeb()`

### ข้อมูลราคาไม่ถูกต้อง

- ตรวจสอบ regex pattern ใน `extractPriceData()`
- ดูใน Console (F12) มีข้อผิดพลาดหรือไม่

### ถูกบล็อก IP

- รอ 1-2 ชั่วโมงก่อนลองใหม่
- เพิ่ม delay ใน `SCRAPER_CONFIG.delayBetweenRequests`

## การพัฒนาต่อ

### เพิ่ม Source อื่นๆ

แก้ไข `scrapeLatestFromWeb()` ให้รองรับ URL อื่นๆ เช่น:
- กรมปศุสัตว์: https://www.dld.go.th
- สำนักงานเศรษฐกิจการเกษตร: https://www.oae.go.th

### เพิ่มการแจ้งเตือน

ใช้ Firebase Cloud Functions trigger เมื่อราคาเปลี่ยนแปลงมากกว่า threshold

### Export ข้อมูล

เพิ่มปุ่ม Export เป็น Excel/PDF สำหรับรายงาน
